# VoyageAI

VoyageAI is an Agentic AI-Powered Intelligent Travel Planning and Companion Platform.

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- AI Service: Python + FastAPI
- Agentic AI: LangGraph
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- AI Models: External pre-trained foundation models
- Development Environment: VS Code
- Version Control: Git + GitHub

## Project Architecture

The project consists of three major application layers:

1. React Frontend
2. Node.js/Express Backend
3. Python/FastAPI AI Service

The application does not train its own machine learning model. It uses existing AI foundation models through APIs and orchestrates them using agentic AI workflows.
